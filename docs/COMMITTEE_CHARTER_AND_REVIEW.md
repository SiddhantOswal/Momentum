## Operating rules

Constructive review → adversarial challenge → evidence check → live scenario → minimal repair → live re-evaluation. Issues record concern, official requirement, severity, reproduction, owner, fix and result. Security/correctness failures block release. D4 evidence belongs to Om; runtime defects belong to engineering. Synthetic history is not factory validation; orchestration is not autonomous planning; demo-session authorization is not verified human identity.
