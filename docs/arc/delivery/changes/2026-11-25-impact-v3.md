# Change record: September impact rebuilt without crack in the objective (2026-11-25)

Approved by Om in the session on 2026-11-25 ("Yes, rerun impact"), founder question G2.

## Why
ARC-ML-03 made crack advisory, so the optimizer no longer counts it. The published September figures (`prepagent.impact_lots_v2`, ₹7,934 a month) came from recommendations that counted crack, so they no longer describe what the optimizer does.

## Commands
1. `bq query --nouse_legacy_sql --maximum_bytes_billed=200000000 --parameter=optimizer_targets:ARRAY<STRING>:[...]` with `sql/impact_batch.sql`: creates `prepagent.impact_recs_v3` (`CREATE TABLE`, not `OR REPLACE`; fails rather than overwrite).
2. `SELECT * FROM prepagent.impact_recs_v3` exported to `recs.json` (read).
3. `node tools/data/impact.ts --recs recs.json --lots <generated history lots.jsonl> --truth <truth.jsonl> --items <items.jsonl> --cost-per-kg 53.3 --out impact_lots.jsonl` (local; the plant rules count all five defects in the true outcome).
4. `bq load --source_format=NEWLINE_DELIMITED_JSON --schema=<schema of prepagent.impact_lots_v2> prepagent.impact_lots_v3 impact_lots.jsonl` (no `--replace`).
5. On `arc/main` only: `sql/dash_kpis.sql` reads `impact_lots_v3`. The live revision (`momentum-00023-yaz`, v2 build) keeps reading `impact_lots_v2` until a release moves traffic.

## Cost
About 73 MB billed for step 1 (the same query billed 73,400,320 bytes on 2026-11-20), 10 MB minimum for step 2, load jobs free. Under one US cent.

## Rollback
Point `sql/dash_kpis.sql` back at `impact_lots_v2`. The v3 tables can stay (nothing reads them otherwise); deleting them needs a separate approval. `impact_recs`, `impact_recs_v2`, `impact_lots` and `impact_lots_v2` are not touched.

## Result
Run 2026-11-25. Job `impact_v3_1795551208`, 73,400,320 bytes billed. `impact_recs_v3` 219 rows, `impact_lots_v3` 219 rows. Net saving ₹7,927 a month (was ₹7,934 with crack in the objective), 149 kg saved, scrap 7.06% to 6.36%, 218 lots changed, 4 made worse (was 3), model's own estimate ₹7,264. `sql/dash_kpis.sql` on `arc/main` reads `impact_lots_v3` (read back with a query on the same day). Evidence: `docs/evidence/impact-v3.json`.
